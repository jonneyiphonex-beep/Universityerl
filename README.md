# Universityerl

نواة أولية لنظام معلومات جامعي متعدد المناطق، مكتوبة لتكون خدماته الخلفية بلغة Erlang/OTP.

## النطاق الحالي

يحتوي `priv/schema.sql` على مخطط علائقي أولي يشمل المناطق والفروع والكليات والأقسام والبرامج، والأشخاص والحسابات والصلاحيات، والطلاب والموظفين، والفصول والمقررات والتسجيل والدرجات وسجل التدقيق.

المخطط يفصل الكيانات لتقليل تكرار البيانات، ويستخدم مفاتيح خارجية وقيود `UNIQUE` و`CHECK` لفرض الاتساق. كلمات المرور لا تحفظ كنص صريح؛ يخزن النظام تجزئتها فقط. المخطط متوافق مع SQLite لتسهيل التطوير المحلي.

## الواجهة التجريبية

افتح `web/index.html` في المتصفح لتجربة لوحة إدارة الهيكل الأكاديمي. الواجهة ثابتة ولا تحتاج إلى تثبيت حزم أو اتصال بالشبكة؛ بياناتها أمثلة محفوظة محليًا في المتصفح، وليست متصلة بقاعدة البيانات أو بخادم Erlang.

تتضمن الواجهة شاشة «مراقبة الموارد». تعرض معلومات يتيحها المتصفح فقط مثل الأنوية المنطقية، وتقدير سرعة الاتصال، وحصة التخزين الخاصة بالموقع. قياس استخدام CPU/RAM والقرص الفعلي ومعدل نقل الخادم يتطلب خدمة مراقبة من Erlang/API؛ ولا تعرض الشاشة أرقامًا تخمينية على أنها قياسات حقيقية.

## الاتصال الضعيف والأمان

- توضع قاعدة البيانات على خادم مركزي؛ لا تتصل أجهزة الفروع بها مباشرة عبر الإنترنت.
- تتواصل تطبيقات الويب/الأجهزة مع API عبر HTTPS، مع صفحات ونتائج مجزأة، وطلبات صغيرة، وضغط الاستجابات، ومفاتيح idempotency للعمليات القابلة لإعادة المحاولة.
- يجب أن ينفذ خادم Erlang التحقق من الصلاحيات لكل طلب، ومعاملات قاعدة البيانات، وسجل التدقيق، ومصادقة آمنة. لا يعد هذا المخطط وحده نظام مصادقة أو API جاهزًا.
- SQLite مناسب لنموذج أولي على خادم واحد؛ فهو يسمح بكاتب واحد في اللحظة نفسها. قبل تشغيل متزامن واسع عبر مناطق متعددة، ينبغي اعتماد PostgreSQL واختبار خطة النسخ الاحتياطي والتعافي.
- يلزم تفعيل المفاتيح الخارجية في كل اتصال SQLite باستخدام `PRAGMA foreign_keys = ON`، واستخدام معاملات للعمليات متعددة الجداول.

## التحقق المحلي

يمكن فحص بنية قاعدة البيانات بأمر:

```sh
sqlite3 university.db < priv/schema.sql
```

هذه مرحلة تأسيس للمخطط فقط، وليست نظامًا جامعيًا مكتملًا. الخطوة التالية هي إنشاء تطبيق Erlang/OTP وواجهات API واختبارات صلاحيات وتدفقات العمل. يجب تثبيت سياسات الجامعة الفعلية، وآلية الدخول الموحد، والتقارير، ومتطلبات التكامل قبل اعتمادها للإنتاج.
